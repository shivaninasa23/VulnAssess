About VulnAssess

Automated Vulnerability Assessment & Security Reporting Tool

Assessment methodology

VulnAssess runs conservative TCP connect discovery with light service version detection and single-response HTTP security header checks. It does not exploit services, authenticate to them, crawl sites, or submit forms.

Severity represents a transparent configuration and exposure heuristic. An open service or absent header is not proof of a vulnerability. Validate all observations.

Responsible use

Use only on systems you own or have explicit written authorization to assess.

Architecture

Flask application factory, SQLAlchemy with Flask-Migrate, SQLite, bounded Nmap and Requests services, and ReportLab.
